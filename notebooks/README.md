# Augmented Lagrangian Method (ALM) Demo

这是一个演示**增广拉格朗日乘子法 (Augmented Lagrangian Method, ALM)** 的项目，用于解决带有等式和不等式约束的非线性优化问题。

## 项目介绍

该项目包含一个 Jupyter Notebook (`ALM_Demo.ipynb`)，展示了如何使用 Python 从头实现 ALM 算法来求解一个具体的运筹优化模型。

### 优化问题模型

*   **目标函数**: 最小化到点 $(1, 2)$ 的欧几里得距离平方。
    $$ \min f(x) = (x_1 - 1)^2 + (x_2 - 2)^2 $$
*   **等式约束**: 解必须位于抛物线上。
    $$ h(x) = x_1^2 - x_2 = 0 $$
*   **不等式约束**: 解必须位于直线下方。
    $$ g(x) = x_1 + x_2 - 1.5 \le 0 $$

## 核心功能

1.  **增广拉格朗日函数构造**:
    实现了包含二次罚项和乘子项的拉格朗日函数 $L(x, \lambda, \mu, \rho)$。
2.  **ALM 迭代算法**:
    *   **子问题求解**: 使用 `scipy.optimize.minimize` (BFGS) 求解无约束子问题。
    *   **乘子更新**: 根据约束违反程度更新 $\lambda$ (等式) 和 $\mu$ (不等式)。
    *   **收敛检查**: 监控约束违反量是否低于容差。
3.  **可视化**:
    使用 `matplotlib` 绘制目标函数等高线、约束边界以及算法寻找最优解的迭代路径。

## 依赖库

*   numpy
*   matplotlib
*   scipy

## 使用方法

直接运行 `ALM_Demo.ipynb` 即可查看算法运行过程及可视化结果。
